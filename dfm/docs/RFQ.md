## 2. Scope

Machine two parts to the CDN drawings: **CDN-001** (nozzle body) and **CDN-002** (mounting flange). Assembly **CDN-000** is reference only, not supplied.

Fasteners (A286, ASTM A453 Gr 660) and the inhibited flexible-graphite gasket are separate procurement, outside this quote.

## 3. Material

**Bar, stainless steel, ASTM A479/A479M-25 Type 316 (UNS S31600), solution-annealed** *(or latest revision at order).*

**Stock:** ⌀160 mm round bar. One heat covers both parts.

## 4. Certification

**EN 10204 Type 3.1** mill test report: chemistry and mechanicals on the delivered heat.

## 5. Inspection deliverables

1. **First Article Inspection report per AS9102B**, Forms 1 to 3, one per detail part.
2. **Dimensional report (CMM)** on the CTQ characteristics in [`inspection-plan.md`](inspection-plan.md) §1.
3. **Material certificate** per §4.
4. **Passivation after machining** per ASTM A967.

These match the CTQ list in [`inspection-plan.md`](inspection-plan.md) §1 and the FAIR forms in §2.

## 6. Drawing package

PDF drawings, not native CAD: **CDN-000 / 001 / 002 at Rev C**, in [`../drawing/`](../drawing/). This is the issued set. It carries position ⌀0.9 Ⓜ, recess 4.5, note N4 solution-annealed, and all incorporated external-review changes.
